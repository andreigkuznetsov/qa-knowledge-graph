# QAIP Qualification Package 1.0

## Purpose

QAIP qualification answers two questions:

- What engineering patterns does QAIP support?
- On which real projects is that support qualified?

## Package Components

- [Supported Engineering Patterns](../supported-engineering-patterns.md) defines the compatibility contract and the precise boundary between Supported, Partial, Planned, and Out of scope patterns.
- [Real Project Corpus](real-project-corpus.md) defines the maintained qualification and discovery repositories, their roles, and their pinned reviewed revisions.

## Qualification Principles

- Qualification is evidence-first.
- Focused fixtures prove exact deterministic boundaries and negative cases.
- Real projects prove integration breadth and practical applicability.
- No single project is the source of product requirements, and corpus coverage is collective.
- Unsupported or Planned patterns must not be presented as implemented.
- A pattern becomes Supported only after focused deterministic tests, practical real-project verification where possible, and documented limitations.

## Release Qualification Use

Future release qualification reviews current Supported and Partial claims, focused regression tests, applicable mandatory qualification projects, compatibility-matrix changes, and relevant pinned repository revisions.
